## 证据边界

- 该 baseline 检查工具轨迹、结束原因、来源存在性和步数，不检查答案事实是否正确或是否完整。
- 原始运行产物 `agent/experiments/runs/evaluation/20260803-024805.json` 默认被 Git 忽略；本报告是提交到仓库的人工复核证据。
- 延迟只代表本次本地模型、网络、语料和索引配置，不应外推为生产 SLA。
- 下一层证据由独立的 Agent LLM-as-Judge runner 生成；第一版 Judge 与 Agent 使用相同模型，存在自评偏差。

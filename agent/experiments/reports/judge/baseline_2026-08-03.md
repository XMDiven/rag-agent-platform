# Agent 答案质量 Judge Baseline（2026-08-03）

## 结论

同模型 LLM-as-Judge 实跑 12 个 Agent case，5 个通过、7 个失败，通过率 41.7%。Agent 和 Judge 均未发生调用或解析错误；失败由评测适用范围不匹配和真实 groundedness 问题组成，不能通过降低阈值或删除 case 掩盖。

## 环境与方法

- Agent 模型：`kimi-k2.6`
- Judge 模型：`kimi-k2.6`
- Judge 独立性：`same_model`
- Embedding：`bge-m3:latest`
- Qdrant collection：`documents`
- 数据集：`agent/experiments/datasets/agent_eval_cases.json`
- 命令：`uv run python -m agent_app.scripts.evaluate_agent_answers`
- 通过规则：相关性、完整性、groundedness 和格式四项均不低于 4 分

## 失败分类

### 评测适用范围不匹配（4 个）

- `empty_question`、`whitespace_question`：它们验证输入降级行为，不是知识回答，RAG groundedness rubric 不适用。
- `summary_literal_text`、`summary_longer_literal_text`：答案依据用户提供的原文，而不是检索来源；共享 RAG Judge 收到 `No retrieved evidence` 后压低 groundedness。

这 4 个结果不能直接解释为 Agent 答案质量失败。后续应为非检索任务定义独立 rubric 或在答案质量数据集中标记评测类型，不能简单提高分数。

### 真实答案质量问题（3 个）

- `paged_attention`：回答加入证据未支持的显存利用率数字、连续批处理关系和扩展类比，groundedness 为 3。
- `chroma_vs_qdrant`：知识库缺少足够 Chroma 证据，回答明确承认缺少资料后仍使用“行业常识”补全，相关性 3、完整性 2、groundedness 2。
- `agent_framework_multi_source`：OpenAI Agents SDK、AutoGen 等来源存在引用错配和超出证据的推断，groundedness 为 3。

## 证据边界

- Judge 与 Agent 使用同一个模型，存在自评偏差；本报告是内部回归信号，不是独立人工结论。
- 原始 JSON 位于 `agent/experiments/runs/judge/20260803-033018.json`，默认被 Git 忽略；本报告只保存人工复核后的汇总和结论。
- 编排回归在同一代码版本下仍为 12/12，说明本报告的失败不是工具执行或流程终止故障。
- 未调整共享 Judge 的 4 分阈值，也未修改 golden set 来追求更高通过率。

## 下一步建议

先把答案质量数据集按任务类型区分为 `retrieval`、`summary`、`direct` 和 `input_validation`，只对 retrieval 使用现有 RAG groundedness rubric。随后优先修复三个检索型 groundedness 失败 case，并用相同问题重跑验证。

Budget tests must prove blocked requests never reach MockTransport, SDK/service retries are zero, output/context/deadline limits are shared consistently, traces exclude headers/errors, SSE callback timing preserves streaming, and generation/Judge allowances stay separate. Integration tests must cover budget exceptions swallowed by legacy fallback, cached getters, repeated runs, failure denominators and reset/restore behavior.

No new dependencies are planned. In-flight remote work cannot be guaranteed stopped by a client deadline; mark overruns as failures, cap output at the provider request and stop subsequent work. General API concurrency/queueing/cancellation guarantees remain A3.
